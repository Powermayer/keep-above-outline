Keep Above Outline - Installation Guide
========================================

SUPPORTED PLATFORMS
-------------------
- Wayland and X11
- Plasma 6.4 through 6.7


REQUIREMENTS
------------
- Qt 6 (Core, Gui, Widgets, Quick)
- KF6 (CoreAddons, ConfigWidgets, KCMUtils)
- Extra CMake Modules (ECM)
- Vulkan headers (required transitively by KWin 6.7+)
- C++20 compiler for Wayland; KWin X11 6.7 requires C++23
- CMake >= 3.20


GUIDED BUILD AND INSTALL
------------------------
Run this script from the unzipped effect folder without elevated privileges:

  ./install.sh

The script checks dependencies and detects every installed supported KWin
compositor. It configures and builds Wayland in build-wayland and X11 in
build-x11. It does not install anything itself. After every selected build
succeeds, it prints the exact sudo cmake --install command that you may run.


MANUAL BUILD AND INSTALL
------------------------
Run these commands from the project root folder.

Wayland:

  cmake -B build-wayland -S . -DKWIN_BACKEND=WAYLAND -DCMAKE_BUILD_TYPE=Release &&
  cmake --build build-wayland &&
  sudo cmake --install build-wayland

X11:

  cmake -B build-x11 -S . -DKWIN_BACKEND=X11 -DCMAKE_BUILD_TYPE=Release &&
  cmake --build build-x11 &&
  sudo cmake --install build-x11

Do not reuse one build directory for the other backend.


ENABLE THE EFFECT
-----------------
1. Open System Settings -> Window Management -> Desktop Effects.
2. Find "Keep Above Outline" under Appearance.
3. Tick the checkbox to enable it.
4. Click the gear icon to configure color, border width, and corner radius.


CONFIGURATION
-------------
Settings are stored in kwinrc under the [Effect-keep-above-outline] group.
You can also edit them directly in ~/.config/kwinrc.

Options:
  UseAccentColor  - Follow the current Plasma accent color (default: true)
  CustomColor     - Color used when UseAccentColor is disabled (default: #3daee9)
  BorderWidth     - Outline thickness in pixels, 1-20 (default: 3)
  BorderRadius    - Corner radius in pixels, 0-30 (default: 0)


Uninstall from the build folder:
---------
sudo xargs rm -f < build-wayland/install_manifest.txt
sudo xargs rm -f < build-x11/install_manifest.txt


Uninstall from anywhere:
---------
Arch / CachyOS / Manjaro:

  sudo rm -f /usr/lib/qt6/plugins/kwin/effects/plugins/keep-above-outline.so \
             /usr/lib/qt6/plugins/kwin/effects/configs/kwin_keep-above-outline_config.so \
             /usr/lib/qt6/plugins/kwin-x11/effects/plugins/keep-above-outline.so \
             /usr/lib/qt6/plugins/kwin-x11/effects/configs/kwin_keep-above-outline_config.so

Fedora / openSUSE Tumbleweed:

  sudo rm -f /usr/lib64/qt6/plugins/kwin/effects/plugins/keep-above-outline.so \
             /usr/lib64/qt6/plugins/kwin/effects/configs/kwin_keep-above-outline_config.so \
             /usr/lib64/qt6/plugins/kwin-x11/effects/plugins/keep-above-outline.so \
             /usr/lib64/qt6/plugins/kwin-x11/effects/configs/kwin_keep-above-outline_config.so

Debian / Ubuntu (KDE Neon, Kubuntu):

  sudo rm -f /usr/lib/x86_64-linux-gnu/qt6/plugins/kwin/effects/plugins/keep-above-outline.so \
             /usr/lib/x86_64-linux-gnu/qt6/plugins/kwin/effects/configs/kwin_keep-above-outline_config.so \
             /usr/lib/x86_64-linux-gnu/qt6/plugins/kwin-x11/effects/plugins/keep-above-outline.so \
             /usr/lib/x86_64-linux-gnu/qt6/plugins/kwin-x11/effects/configs/kwin_keep-above-outline_config.so
