Keep Above Outline - Installation Guide
========================================

SUPPORTED BACKENDS
------------------
- Wayland is the default and continuing KWin target.
- X11 is supported on Plasma 6.4 through 6.7 only.
- Plasma 5.27 is not supported.
- X11 requires the distribution's KWin X11 runtime and development package.


AUTOMATIC DEPENDENCY CHECK AND BUILD
------------------------------------
Run this from the project root:

  ./install.sh

The helper checks dependencies and detects every installed supported KWin
compositor. It configures and builds Wayland in build-wayland and X11 in
build-x11. It never requests elevated privileges and never installs files.
After every selected build succeeds, it prints the exact sudo cmake --install
command that you may run yourself.


REQUIREMENTS
------------
- Qt 6 (Core, Gui, Widgets, Quick)
- KF6 (CoreAddons, ConfigWidgets, KCMUtils)
- Extra CMake Modules (ECM)
- Vulkan headers (required transitively by KWin 6.7+)
- C++20 compiler for Wayland; KWin X11 6.7 requires C++23
- CMake >= 3.20

The package commands are documented in README.md. Install the runtime and
development packages for each backend you intend to build.


MANUAL BUILD (Run commands from the project root folder)
---------------------------------------------------------
Wayland (default):

  cmake -B build-wayland -S . -DKWIN_BACKEND=WAYLAND -DCMAKE_BUILD_TYPE=Release
  cmake --build build-wayland &&
  sudo cmake --install build-wayland

X11:

  cmake -B build-x11 -S . -DKWIN_BACKEND=X11 -DCMAKE_BUILD_TYPE=Release
  cmake --build build-x11 &&
  sudo cmake --install build-x11

Do not reuse one build directory for the other backend.


INSTALL
-------
Install only the backend or backends that built successfully:

  sudo cmake --install build-wayland
  sudo cmake --install build-x11


ENABLE THE EFFECT
-----------------
1. Open System Settings -> Window Management -> Desktop Effects.
2. Find "Keep Above Outline" under Appearance.
3. Tick the checkbox to enable it.
4. Click the gear icon to configure color, border width, and corner radius.


UNINSTALL
---------
CMake has no built-in uninstall command. Remove exactly the files recorded by
the backend build's install manifest:

  sudo xargs rm -f < build-wayland/install_manifest.txt
  sudo xargs rm -f < build-x11/install_manifest.txt

Only run the command for a backend that you installed.


CONFIGURATION
-------------
Settings are stored in kwinrc under the [Effect-keep-above-outline] group.
You can also edit them directly in ~/.config/kwinrc.

Options:
  UseAccentColor  - Follow the current Plasma accent color (default: true)
  CustomColor     - Color used when UseAccentColor is disabled (default: #3daee9)
  BorderWidth     - Outline thickness in pixels, 1-20 (default: 3)
  BorderRadius    - Corner radius in pixels, 0-30 (default: 0)
